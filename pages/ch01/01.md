<div class="unit">L01-U02 · 浏览器与服务器 · 15 分钟</div>

# 浏览器并没有直接调用 Python

<div class="cols mt-6">
<div class="panel"><h3>同一个 Python 程序里</h3>

```python
question = get_question(3)
```

<p>当前程序直接调用函数，<br>直接传入一个整数。</p></div>
<div class="panel"><h3>浏览器访问一个地址</h3>

```http
GET /questions/3 HTTP/1.1
Host: 127.0.0.1:8000
```

<p>发送 HTTP 请求，<br>由服务器与应用接力处理。</p></div>
</div>
<div v-click="1" class="callout">浏览器不知道 Python 函数名。<br>它只按约定的<b>方法与地址</b>提出请求，收到<b>状态与数据</b>。</div>
<div class="note">接口是这份对外约定；端点函数只是服务器内部的一段实现。</div>

# Uvicorn 接进来，FastAPI 找函数

<div class="cols mt-6">
<div class="panel"><h3>Uvicorn · ASGI 服务器</h3><ul><li>监听 <code>8000</code> 端口</li><li>接收连接、处理 HTTP</li><li>按 ASGI 约定交给应用</li></ul><p class="note">不决定“编号 3 是否存在”。</p></div>

<div class="unit">L01-U05 · 类型对照的原因</div>

# 字符串 "3" 与整数 3，并不相等

<div class="cols mt-6">
<div class="panel"><h3>没有 int 声明</h3><p>路径值仍是字符串。</p><pre class="plain-output">question["id"] == qid
       3       == "3"
               ↓
             False</pre></div>
<div class="panel"><h3>有 int 声明</h3><p>框架先转换，再传参。</p><pre class="plain-output">question["id"] == qid
       3       == 3
               ↓
              True</pre></div>
</div>
<div class="callout">Python 的类型注解本身不是自动强制检查；<br>这里是 FastAPI 读取声明并处理请求参数。</div>
<div class="note">实验结束恢复 <code>qid: int</code>，停止并重启。转为整数仍不代表记录存在。</div>
